# 🎮 游戏开发模拟器 (Game Dev Simulator)
> 从 800 元起步，经营你的独立游戏工作室，在 bug 与爆炸中艰难求生。

## 📖 简介

《游戏开发模拟器》是一款**回合制策略经营游戏**。你将扮演一位独立游戏开发者，从仅有 800 元资金和一个人的团队开始，通过**版本更新、招募员工、升级服务器硬件**，逐步扩大玩家规模。

**你能带领工作室走多远？是成为游戏巨头，还是倒在资金链断裂的前夜？**  

## ✨ 功能特性

- **🛠️ 真实版本迭代**：小更新修复 1 个 bug → 补丁版本+1；大更新修复 3 个 bug → 次版本+1；重写源代码可清空所有 bug → 主版本+1。
- **👥 多元团队招募**：萌新、普通、大神、管理员四种职业，各有优劣（大神可抵挡部分负面事件）。
- **💻 硬件压力系统**：购买/更换 CPU/GPU，压力公式为 `CPU压力 = 人数 × 1.5`、`GPU压力 = 人数 × 1.2`；超过性能点服务器会爆炸，连续爆炸周数惩罚递增。
- **📅 动态月份效应**：寒假（2月）和暑假（7月、8月）玩家数快速增长（每次增长系数递减，单次不超过 10000 人），1 月、6 月为淡季人数减少。
- **🎲 随机事件系统**：口碑爆棚、黑客攻击、竞品发布、数据泄露丑闻等十余种事件，动态难度影响正负面概率。
- **🏆 成就系统**：13 个成就（百人斩、千人斩、万人迷、技术革新、绝对防御、铁饭碗、硬件狂魔等），达成即可获得一次性奖励。
- **💾 存档 / 读档**：支持下载为 `.gds` 文件，随时保存和恢复游戏进度。
- **📈 压力曲线图**：线上功能开启后显示最近 20 周的 CPU/GPU 压力变化。
- **✨ 新手教程**：首次进入游戏会弹出引导，介绍各个界面功能，可跳过。

## 🎮 游戏操作说明

### 主要界面区域
- **左侧上方**：核心资源面板（经费、精力、技术力、声誉、玩家数、bug 数、版本、爆炸周数、加班压力）。
- **左侧中部**：行动按钮（小更新、大更新、重写、开发线上、加班、学习、广告、鸽、募捐、团建）。
- **左侧下方**：团队招募区，可招募四种职业（每周最多 4 人）。
- **右侧上方**：硬件商店与压力监控区（购买/更换 CPU/GPU，查看实时压力及历史曲线）。
- **右侧下方**：成就殿堂与事件日志。

### 常用行动
| 行动       | 消耗（行动值/经费/精力/技术） | 主要效果                                 |
|------------|-------------------------------|------------------------------------------|
| 小更新     | 1 / 8💰 / 5% / 5              | 修复 1 个 bug，人数+1~2，补丁版本+1       |
| 大更新     | 2 / 20💰 / 10% / 20           | 修复 3 个 bug，人数+5~10，次版本+1        |
| 重写       | 4 / 180💰 / 40% / 100         | 修复所有 bug，人数+20~50，主版本+1         |
| 开发线上   | 10 / 1000💰 / 50% / 200       | 开启服务器压力系统，人数 ×1.1             |
| 加班       | 工资20% 经费 / 20% 精力       | 获得 3~5 额外行动，下周行动上限-1          |
| 鸽         | 1                            | 精力 +5%~15%，声誉 -0.01~0.03（唯一加精力）|
| 团建       | 2 / 10💰 / 5%                | 行动上限永久 +1（最高 10）                |

鼠标悬停任何按钮可查看详细说明。
